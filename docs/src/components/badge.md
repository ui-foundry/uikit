# Badge <span class="text-size-3.5">`<ui-badge/>`</span>

Badges are used to draw attention and display statuses or counts.

The Badge component serves the purpose of presenting information to the user. It can display some quick info and can be customized to draw the user's attention by modifying its color, size and other properties.

## Usage
<ui-flex gap="10">
	<ui-badge radius="xs">Badge</ui-badge>
    <ui-badge size="20" circle>8</ui-badge>
    <ui-badge radius="pill">99</ui-badge>
    <ui-badge radius="sm">999</ui-badge>
    <ui-badge>99+</ui-badge>
</ui-flex>
