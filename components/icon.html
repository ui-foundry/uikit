Icon <ui-icon/> ​

Icons are symbols that can be used to represent various options within an application. They can convey meaning quickly and effectively, making them a valuable addition to any user interface.

Custom Icons ​

Custom icons can be loaded individually with the src attribute. Only SVGs on a local or CORS-enabled endpoint are supported.
